2. 기능 요구사항 (FR)

파이프라인 5단계에 대응하는 5개 요구사항

아래 방향키(↓)로 FR-01 ~ FR-05 확인

FR-01. 크롤링 (정보 수집)

정의진단 대상 웹사이트를 크롤링하여 페이지 및 입력 지점 목록을 자동 수집
세부 내용대상 도메인 내 페이지 자동 탐색 (링크 추적)
GET/POST 파라미터, 폼 필드, 쿠키 등 입력 지점 목록화
수집 결과를 구조화 데이터(JSON 등)로 저장, 다음 단계에 전달
인증 필요 페이지는 사전 설정된 세션으로만 접근 (허용 범위 내)

FR-02. LLM 기반 진단 도구 선택

정의수집된 입력 지점 특성을 LLM이 분석하여 SQLi/XSS 스캔 여부·방식을 판단·선택
세부 내용파라미터 유형·응답 특성 등을 근거로 SQLi/XSS 각각의 스캔 필요 여부 판단
판단 근거를 로그로 기록 (사실과 추측 구분)
선택 결과에 따라 다음 단계의 페이로드 세트·강도 결정

FR-03. 자동화 도구 실행 (SQLi/XSS 스캔)

정의선택된 스캔 로직에 따라 SQLi/XSS 탐지용 자동화 도구를 실행, 원시 결과 수집
세부 내용SQLi: 에러기반/블라인드(시간지연) 등 페이로드 주입 및 응답 비교
XSS: reflected/stored 여부 확인을 위한 페이로드 주입 및 반사 여부 확인
요청 속도 제한 등 운영 영향 최소화 옵션 적용
모든 요청·응답 원문 로깅

FR-04. LLM 판단 (취약점 확정 및 재실행)

정의자동화 도구의 원시 결과를 LLM이 분석해 오탐 여부 판단, 필요 시 재실행
세부 내용응답 내 취약점 신호(에러 메시지, 반사된 페이로드 등) 해석
오탐 가능성 있는 경우 페이로드를 조정한 재현 요청을 자동 생성·재실행
확정(Confirmed) / 미확인(Unconfirmed) 상태와 판단 근거를 함께 기록

FR-05. 리포트 생성

정의확정된 취약점을 사람이 읽을 수 있는 보고서 형태로 산출
세부 내용취약점 별 위치(URL/파라미터), 유형, 판단 근거, 재현 PoC(요청·응답) 명시
마크다운 또는 HTML 형태로 보고서 자동 생성
원본 요청·응답 로그를 첨부하여 재현성 확보
